## [OpenGLLL](https://github.com/lucasvm01/OpenGLLL)
Projeto de desenvolvimento de uma engine 3D, sem utilizar bibliotecas e recursos  3D do openGL, apenas transformações matemáticas de pontos no plano para o espaço tridimensional.

- Demo do teste CubeRotation, onde uma imagem é adicionada como textura num cubo, que pode ser movido e rotacionado pelo espaço:
![me](https://github.com/lucasvm01/PortfoLLLio/blob/main/OpenGLLL_demo.gif)

Serve também como estudo do funcionamento do openGL.

WIP.

## [p5_testing](https://github.com/lucasvm01/p5_testing)

Exercícios pessoais para estudo de funcionamento da engine Processing 5 JS.
  No arquivo cg_basic.js, da mesma forma que o repositório OpenGLLL, utilizei de pontos no plano e transformações matemáticas para fazer um cubo rotacionar no espaço.
  Nos arquivos fourier_series_linear.js e fourier_series_sawtooth.js, utilizei de somatórios "infinitos" para transformar somas de funções senoides em funções do primeiro grau e modular.

##  [API-Deputados](https://github.com/lucasvm01/API-Deputados)

Projeto de introdução ao frontend (sem framework), onde realizei um site com apresentação dos deputados eleitos no Brasil, podendo filtrar por partido e verificar seus gastos por mês.
Ultimamente, é um estudo de consumo de API, utilizando como exemplo a API de deputados disponibilizada pelo governo do país.
